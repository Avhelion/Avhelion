## 🌌 About Me

Hey! I'm **Jason**, better known online as **Avhelion**.

I'm a developer from the Netherlands who enjoys building things for the
games I actually play.

Most of my projects start with a simple idea. I get a first version working,
test it in-game, break something along the way, fix it and keep improving it
until it becomes something I'm happy with.

My work is mainly focused on:

💜 **Minecraft** — plugins, mods, Kingdom systems & magic  
🩷 **GTA V / LSPDFR** — Dutch police plugins & gameplay systems  
💙 **Roblox** — football tools, MPS systems & UI

I'm still learning new things with every project, especially around Java,
plugin architecture, databases and multiplayer systems.

# 🪐 Currently Building

## 🔮 Avhelion Wands

> **A custom Minecraft magic system built for Kingdom-style gameplay.**

Avhelion Wands started as an experiment with custom Minecraft magic and
is growing into a system where different wands can have their own identity,
spells and abilities.

### 🌑 Current systems

- 🪄 Multiple wand architecture
- ✨ Custom spell casting
- 🌌 Area-based abilities
- 🔌 Client/server spell handling
- 💫 Custom visual effects
- ⌨️ Command-based wand management
- 🌑 Dark Realm
- ⚔️ More spells & wands planned

# 🚓 GTA V / LSPDFR Development

A big part of my development work revolves around bringing more
**Dutch police gameplay** to GTA V / LSPDFR.

## 📱 Dutch MEOS

A custom Dutch-style police information system for LSPDFR.

The project is designed around recreating a more complete police workflow
inside GTA V instead of only showing basic information.

### 🔹 Systems

- 🪪 ID card scanning
- 🚘 Driving licence information
- 👤 Person records
- 📂 Police history
- 🚔 Vehicle information
- 🟢 Status indicators
- 📱 Mobile MEOS interface
- 📝 Incident handling workflows
