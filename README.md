## 🔮 Avhelion Magic Wands

> **A Minecraft magic framework built around unique wands and spells.**

Each wand can have its own identity, abilities and spell collection while
sharing one expandable magic framework.

### Current systems

`Multiple Wands` • `Spell Casting` • `Spell Selection`  
`Area Abilities` • `Client / Server Handling`  
`Visual Effects` • `Wand Commands`

### 🌑 Dark Realm

The first major spell creates a temporary dark realm around the caster.

Enemies lose visibility while the caster rises into the air surrounded by
dark effects. The system is being expanded towards temporary environmental
transformation and more powerful realm mechanics.

| Control | Action |
|---|---|
| `LEFT CLICK` | Cast spell |
| `RIGHT CLICK` | Aim / interact |
| `SHIFT + RIGHT CLICK` | Return to spell list |

## 📱 Dutch MEOS

> **A Dutch police information system for GTA V / LSPDFR.**

A mobile police interface designed around Dutch police workflows rather
than a standard game menu.

### Systems

`ID Scanning` • `Person Records` • `Driving Licences`  
`Police History` • `Vehicle Information` • `Status Indicators`  
`Manual Search` • `Mobile UI` • `Custom Navigation`

The goal is to connect existing LSPDFR information into one immersive
police workflow.
